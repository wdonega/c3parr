Turns the audio into text when there is no usable subtitle. It can run here or on a separate server (another container, a machine with a GPU).

arrow_drop_down

Uses the engine in Settings → Engines. On the CPU it takes about 10 min or more per hour of video; with a GPU build of whisper.cpp, 1-2 min.

Any server with /v1/audio/transcriptions: whisper.cpp (ghcr.io/ggml-org/whisper.cpp:main-vulkan running whisper-server --inference-path /v1/audio/transcriptions), speaches or LocalAI. The URL ends in /v1.

The onerahmet/openai-whisper-asr-webservice image (:latest-gpu for NVIDIA). If Bazarr already uses one, point to the same server. The URL is the server root, e.g. http://whisper:9000.
